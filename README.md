# Registro certificado de llamadas

Aplicación web instalable para iPhone: registra grabaciones, calcula sus huellas, obtiene sellos de tiempo RFC 3161, genera el acta y el paquete de prueba y transcribe en el propio teléfono.

Este repositorio solo contiene la aplicación ya construida. No contiene grabaciones, actas ni datos de ningún usuario: todo eso se guarda únicamente en el iPhone de quien la usa.

Dirección de la aplicación: https://periclesv.github.io/llamadas/
